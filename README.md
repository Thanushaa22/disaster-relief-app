# 🌍 Disaster Relief Management System

A full-stack web application designed to streamline disaster response and relief operations. The system enables users to report emergencies, request assistance, and helps administrators manage disaster-related information efficiently through a centralized platform.

## 🚀 Features

* 🔐 User Authentication (Login & Registration)
* 📢 Emergency Incident Reporting
* 🆘 Relief Request Management
* 📊 Disaster Information Dashboard
* 🗄️ Database Integration with MySQL
* 🔄 RESTful API Communication
* 📱 Responsive User Interface
* 🛡️ Secure Backend Architecture

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/Thanushaa22/disaster-relief-app.git
cd disaster-relief-app
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
